# AMC v Regal — NYC Recliner Showtimes

Live dashboard combining showtimes from Emma's 4 favorite NYC recliner theaters:

- Regal Battery Park
- Regal Union Square
- AMC 34th Street 14
- AMC Village 7

**Live page:** https://escully-cpu.github.io/amc-v-regal/

Source data is Fandango's internal showtimes API (no key, browser-impersonated
session). Movie posters are scraped from Letterboxd. Cards are filtered to
recliner-only auditoriums (or the entire theater for venues that are fully
recliner but where Fandango omits the amenity tag).

## Refresh

The page is regenerated by a launchd timer (`com.escully.nyc-movies`) at
**9:10 AM, 1 PM, and 5 PM** daily and pushed to this repo by `run.sh`.

Manual rebuild + push:

```bash
./run.sh
```

## Files

- `update_showtimes.py` — fetches Fandango + Letterboxd, renders `index.html`
- `run.sh` — wrapper called by launchd; runs the updater then `push_to_github.sh`
- `push_to_github.sh` — commits + pushes index.html when it changes
- `com.escully.nyc-movies.plist` — LaunchAgent definition
- `index.html` — rendered dashboard
